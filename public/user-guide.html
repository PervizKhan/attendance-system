📖 System Overview

Oxford Group of Colleges Attendance System is a state-of-the-art face recognition-based attendance management system that automatically marks student and staff attendance using facial recognition technology. Parents receive instant email notifications when their child arrives at college.

🚀 Admin Quick Start

1
First Time Setup

Go to https://oxford-attendance.vercel.app/setup to create your admin account.

Enter: Name, Email, Password, and Setup Key (provided by system administrator).

2
Login

Go to /admin/login and login with your email and password.

3
Add Students/Staff

Use the navigation tabs to add students or staff members with their details.

4
Register Faces

Click "Register Face" next to each student/staff to capture their face using webcam.

⚙️ Daily Operations

🏫 Morning Routine

  • Ensure the gate phone/tablet is ON and the kiosk page is open
  • Student kiosk: /kiosk/gate
  • Staff kiosk: /kiosk/staff (if separate gate)
  • Students/Staff look at camera → Face recognized → Attendance marked automatically
  • Parents receive email notification within 5 minutes
  • Late arrivals (after 8:30 AM) are marked as "⚠️ Late"

👨‍💼 Admin Tasks

  • Add New Student: Go to Students tab → Click "+ Add Student" → Fill details → Save
  • Register Face: Click "Register Face" next to student → Capture face via webcam
  • Mark Absent: Go to Attendance tab → Click "Mark Absent (After 9 AM)"
  • Export Report: Go to Attendance tab → Select date range → Click "Export CSV"
  • Add Holiday: Go to Holidays tab → Click "+ Add Holiday" → Enter date and name
  • Retrain Face: Go to Face Training tab → Select person → Click "Retrain"

📝 Student Registration Process

1
Add Student Details
Go to Students tab → Click "+ Add Student" → Enter:
  • Student ID (e.g., OXF2024001)
  • Full Name
  • Father's Name
  • Class
  • Parent Email (required for notifications)
  • Parent WhatsApp Number (optional)
2
Register Face
Click "Register Face" next to the student → Allow camera access → Student looks at camera → Click "Capture Face" → Wait for "✓ Face registered successfully"
3
Bulk Import (Multiple Students)
Go to Import tab → Download CSV template → Fill student data → Upload CSV file

👨‍👩‍👧 Parent Portal

URL: https://oxford-attendance.vercel.app/parent-attendance

Parents can check their child's attendance by entering their registered WhatsApp number.

Features:

  • View attendance history with pagination (20 records per page)
  • Export attendance to Excel (CSV) or PDF
  • View summary statistics (total days, present, absent, attendance rate)
  • Print attendance report directly

🔧 Troubleshooting

IssueSolution
Camera not workingAllow camera permission in browser settings → Refresh page
Face not recognizedRe-register face in admin panel → Ensure good lighting → Look directly at camera
Student not found in kioskStudent needs face registration first. Go to Students tab → Click "Register Face"
Email not receivedCheck spam folder. Ensure parent email is correct in student record
Duplicate attendanceSystem prevents duplicate marking for same day
Holiday marked but attendance possibleGo to Holidays tab → Add holiday date → No attendance will be accepted

✅ Best Practices

  • Register faces in good lighting - Helps recognition accuracy
  • Keep student emails updated - Parents won't miss notifications
  • Add holidays in advance - Prevents attendance marking on holidays
  • Review logs regularly - Track who made changes to the system
  • Take weekly backups - Use Backup tab to download data
  • Keep the kiosk device plugged in - Ensure it's always charged
  • Retrain faces periodically - Improves recognition accuracy
